About Chromatone

Color → Monochrome Pattern Encoding

Chromatone is a halftone engine that encodes both color and brightness into black-and-white patterns. Traditional halftones only represent value (light/dark). Chromatone goes further — it represents hue, saturation, and value all at once.

How It Works

Colors are converted from RGB to an artistic RYB-like model, then mapped to directional marks:

  • / forward slashes → Red
  • \ backslashes → Blue
  • • dots → Yellow
  • ■ squares → Gray/Black

Secondary colors use combinations: Orange = / + •, Green = \ + •, Purple = X (cross-hatch).

Line thickness encodes brightness. Saturation controls how broken/continuous the lines appear.

What's It For?

  • E-ink displays — Kindle, reMarkable, and other monochrome screens
  • Monoprinting — posters, risograph, screen printing, T-shirts
  • Tattoo stencils — transfer-ready patterns
  • Accessibility — color information for colorblind viewers
  • Artistic effect — create striking monochrome designs

The Process

This engine was built through iterative calibration — testing color wheels, portraits, and real-world images to tune the hue boundaries and value curves until the output felt perceptually accurate and aesthetically rich.
